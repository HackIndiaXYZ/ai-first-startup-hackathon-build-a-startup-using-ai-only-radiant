# DukaanAI

**Talk to your shop. DukaanAI keeps the books.**

Voice-first AI co-pilot for Indian kirana shops. Talk to your shop and let DukaanAI keep the books.

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and [http://localhost:3000/api/health](http://localhost:3000/api/health).
